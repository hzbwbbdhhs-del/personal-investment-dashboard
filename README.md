# 个人投资仪表盘

一个本地优先的单页投资观察工作台，适合 Mac 与手机查看。当前版本使用用户已知信息建立初始估算，并用“估算 / 待确认 / 演示值 / 未接入”明确区分数据状态。

## 本地运行

在项目目录执行：

```bash
python3 server.py
```

打开 `http://127.0.0.1:4173/`。

市场温度通过 FRED 免费公开 CSV 快照接入，无需注册或 API Key：自动读取纳指100、标普500、VIX、VXN、美国10年期国债收益率、USD/CNY，以及联邦基金利率、CPI、PCE、失业率和非农就业，并按用户规则计算市场温度。GitHub Actions 每 30 分钟检查公开快照；指标本身主要是日线或月度数据，不代表盘中实时。基金净值通过东方财富公开历史净值接口读取，GitHub Actions 每天北京时间09:02至17:52约每10分钟检查一次、18:02至次日01:57约每5分钟检查一次；失败自动重试并保留上次成功净值。网站打开时每分钟读取 GitHub 上最新的净值、行情快照；QDII 限额页面每15分钟读取 GitHub 上的第三方快照。定时任务和公开接口可能延迟，无法保证公布瞬间更新。

总览的总资产、分类占比和持仓市值随最新已公布净值重新计算：有份额时用份额×单位净值；没有份额时用录入市值×最新净值÷录入日期对应的最近可得净值。原始持仓基准是支付宝2026-10-07与直销2026-10-03的截图；网站无法自动读取支付宝/直销账户的买卖、分红、份额变化和现金余额，因此这个总资产是“最新净值估算”，不是真实账户余额。今日收益显示各只基金实际净值日；有可用净值时统一标“已更新”，包括今天才公布前一交易日净值的 QDII。该标签仅表示当前数据源已取得这只基金的净值，不保证公告时间是今天；具体日期以每只基金标注的净值日为准。若以后接入 `MASSIVE_API_KEY`，行情层才会升级为盘中数据。不要把真实密钥放进 `dist/`、提交到 Git，或直接发在聊天里。

## 当前已实现

- 资产总览、分类比例、纳指回撤分档规则
- 持仓录入、成本、份额、月定投金额及本地保存
- 纳指 / 标普 / VIX / VXN / 美债 10 年期 / USD-CNY 的行情槽位
- 美联储、CPI / PCE、就业、EPS 与资本开支的宏观时间线
- QDII 关注清单，区分基金公司直销与支付宝等代销渠道
- “只有重大变化才提醒”的本地开关
- 本地 JSON 导出
- `market-data.json` 公开日线快照，浏览器每 60 秒检查 GitHub 最新版本，GitHub Actions 每 30 分钟刷新一次
- “市场与宏观”页嵌入 TradingView 官方面积折线图组件：QQQ / SPY 为可看盘中走势的 ETF 参考，纳指100 / 标普500另提供 FRED 指数日线图，并可切换 VIX、VXN、美国 10 年期收益率和 USD/CNY。原指标弹窗也改为面积图。TradingView 免费组件不开放 NASDAQ:NDX 指数的嵌入展示，因此不能将 QQQ 冒充 NDX 点位。组件行情可能延迟或受嵌入权限限制，且不向本站提供可计算的数据 API。市场温度仍由 FRED 日线快照计算；如 TradingView 被网络或浏览器拦截，组件可能无法显示。

## 后续接入建议

不要把行情和宏观 API Key 放在浏览器代码里。当前本地版已用 `server.py` 做服务端代理；部署到 Vercel 或 Cloudflare Pages 时，把同样逻辑迁移到 serverless function / Worker，由服务端读取密钥、定时拉取数据、整理成快照，再让前端只读取快照。

- 行情：Polygon / Massive、Finnhub、Alpha Vantage 等，通常需要 Key；实时权限、历史深度和商业使用可能收费。
- 宏观：FRED、BEA、BLS、Treasury 等；部分公共数据可直接读取，部分需要申请 Key，并可能有频率或延迟限制。
- 基金状态：优先读取基金公司公告和交易规则，再补充支付宝等代销渠道状态，并保留公告时间和来源。

供应商的限额、价格和条款会变化，正式接入前请以当前官方文档为准。
