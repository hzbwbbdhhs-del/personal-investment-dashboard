# 个人投资仪表盘

一个本地优先的单页投资观察工作台，适合 Mac 与手机查看。当前版本保留用户核对的账户快照，并区分最新净值估算、交易在途、检查失败及数据日期较早等状态。

## 本地运行

在项目目录执行：

```bash
python3 server.py
```

打开 `http://127.0.0.1:4173/`。

市场温度通过 FRED 免费公开 CSV 快照接入，无需注册或 API Key：自动读取纳指100、标普500、VIX、VXN、美国10年期国债收益率、USD/CNY，以及联邦基金利率、CPI、PCE、失业率和非农就业，并按用户规则计算市场温度。GitHub Actions 每 30 分钟检查公开快照；指标本身主要是日线或月度数据，不代表盘中实时。基金净值通过东方财富公开历史净值接口读取，GitHub Actions 每天北京时间09:02至17:52约每10分钟检查一次、18:02至次日01:57约每5分钟检查一次；失败自动重试并保留上次成功净值。网站打开时每分钟读取 GitHub 上最新的净值、行情快照；QDII 限额页面每15分钟读取 GitHub 上的第三方快照。定时任务和公开接口可能延迟，无法保证公布瞬间更新。

估值水位直接从 [Dollar Liquidity 的公开阅读版](https://dollarliquidity.com/en/valuation)在浏览器中读取，不把其非开放许可的估值序列写入本站仓库。页面打开时、重新切回页面时以及每 10 分钟检查一次；来源网页可能有约 1 小时缓存，数字是最新可得日线，不是盘中实时。预期市盈率、盈利收益率、近 5 年分位和估值日自动读取；日变化和近 5 年中位数只有 2026-10-09 的完整来源页面核对快照，页面会在估值日不匹配时自动隐藏，不把旧值当最新。来源若不可用则留空并提示。估值仅供观察，不自动改变纳指回撤分档。

总览的总资产、分类占比和持仓市值随最新已公布净值重新计算：有份额时用份额×单位净值；没有份额时用录入市值×最新净值÷录入日期对应的最近可得净值。支付宝持仓基准已更新为2026-10-28录屏（62笔逐项核对），直销沿用2026-10-03的10笔记录，用户2026-10-28确认无交易；网站无法自动读取支付宝/直销账户的买卖、分红、份额变化和现金余额，因此总览显示合并参考金额，并列支付宝录屏账户快照。4笔含赎回在途、尚未拆分的持仓保留录屏金额，暂停自动估值；在途款不重复加到总额，也不计为可用现金。今日收益显示各只基金实际净值日；收益按实际净值日分组，只汇总选定日期且可计算的持仓，展示覆盖数量；不会将不同净值日相加称为今日收益。成功检查且日期合理的净值标“已更新”；检查失败或日期较早会显式提示。该标签仅表示当前数据源已取得这只基金的净值，不保证公告时间是今天；具体日期以每只基金标注的净值日为准。若以后接入 `MASSIVE_API_KEY`，行情层才会升级为盘中数据。不要把真实密钥放进 `dist/`、提交到 Git，或直接发在聊天里。

### QDII 公告自动解析（2026-10-11）

- 项目内保留 MIT 开源 `aiten2/qdii-purchase-limits` v1.12.7，固定上游提交 `cc86f1a19b9df2c1eb90a0622f4c25f29b6f5aaf`，许可证及离线测试保留。未启用它的邮件、飞书、macOS 定时任务。
- `scripts/refresh-qdii-evidence.mjs` 使用其正式 CLI 解析人民币场外纳指100/标普500公告，按代销、直销、生效日、单基金账户单日累计口径提取证据；首轮约数分钟，后续复用 PDF 事件缓存。公告检查约每小时，销售状态现有15分钟任务保持；免费公开源和调度不保证即时更新。
- `promise96319/qdii/data/latest.json` 用于每日天天基金参考交叉检查，保留其源站更新时间；不能用作支付宝/直销实际额度，两者共享部分上游，不是独立认证。
- 支付宝公开页只能确认在售状态，实际订单额度没有公开接口接入。主动QDII不在此公告解析器范围内，仍显示未核实，不把原手工公告数字冒充当前额度。原手工记录文件保留，但不再作为当前额度展示或排序依据。
- 运行：先安装 `npm ci --prefix vendor/qdii-purchase-limits --omit=optional --ignore-scripts`，再运行 `node scripts/fetch-qdii-limits.mjs && node scripts/refresh-qdii-evidence.mjs`。缓存仅保存在 `.cache/qdii-engine`，不发布；需要重新采集可加 `--force`。测试：`node scripts/test-qdii-ui.mjs`；上游离线测试：`node vendor/qdii-purchase-limits/scripts/check-release.js`。

## 后续接入建议

不要把行情和宏观 API Key 放在浏览器代码里。当前本地版已用 `server.py` 做服务端代理；部署到 Vercel 或 Cloudflare Pages 时，把同样逻辑迁移到 serverless function / Worker，由服务端读取密钥、定时拉取数据、整理成快照，再让前端只读取快照。

- 行情：Polygon / Massive、Finnhub、Alpha Vantage 等，通常需要 Key；实时权限、历史深度和商业使用可能收费。
- 宏观：FRED、BEA、BLS、Treasury 等；部分公共数据可直接读取，部分需要申请 Key，并可能有频率或延迟限制。
- 基金状态：优先读取基金公司公告和交易规则，再补充支付宝等代销渠道状态，并保留公告时间和来源。

供应商的限额、价格和条款会变化，正式接入前请以当前官方文档为准。
